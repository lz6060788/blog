# 文章内容载体与发布状态

## 编辑与展示

编辑页提供「可视化编辑 / 源码 / 文章预览」，使用「插入视频 / HTML」加入视频、音频、HTML 源码或网页地址。预览和公开详情页共用服务端渲染器。

内容仍存放在原有 Markdown 正文字段，无需数据库迁移。可以混合文字、图片和以下内容块：

````markdown
```video 演示视频
https://example.com/demo.mp4
```

```audio
https://example.com/narration.mp3
```

```html-preview 交互演示
<style>button { padding: 12px; }</style>
<button onclick="this.textContent='完成'">点击试试</button>
```

```embed 网页演示
https://example.com/demo.html
```
````

- 视频、音频使用浏览器支持的直接媒体文件地址，不是视频站点的普通观看页；允许 HTTPS 地址和站内绝对路径。
- `embed` 用于 HTML 页面或提供商允许嵌入的播放器 URL。对方的 CSP / X-Frame-Options 可阻止嵌入，本站不能绕过。
- HTML 在 `sandbox="allow-scripts"` 的 iframe 中运行，不赋予 same-origin、顶层导航、弹窗、表单提交能力。内嵌 HTML 另加 CSP，禁止网络 API 请求，允许 HTTPS 脚本、样式、图片等资源。HTML 应为自包含文档，外部资源使用绝对地址。
- 普通 `html` 代码围栏继续展示源码。原始顶层 HTML 块也在隔离容器中显示。包含 HTML 标记的正文使用源码编辑，避免富文本转换丢失内容；围栏内部反引号会自动转义为更长的外层围栏。
- 视频默认显示播放控件，不自动播放。HTML 容器高度为 520px，长内容在容器内滚动。

## 状态与草稿的关系

公开状态由 `posts.published` 决定；编辑内容放在 `post_drafts`。`post_drafts.post_id` 的唯一索引保证每篇文章最多一份关联草稿。

| 状态 | posts | post_drafts | 访客可见 |
| --- | --- | --- | --- |
| 新文章待发布 | 无 | 独立草稿，post_id 为空 | 否 |
| 已发布 | published=true | 无 | 是 |
| 已发布，正在修订 | published=true，保留线上快照 | 关联修订草稿 | 仅线上快照 |
| 已撤回，待发布 | published=false，保留原 ID 与线上快照 | 关联草稿 | 否 |

### 转换规则

1. 新文章发布：在事务中创建文章、复制标签并删除草稿，文章 ID 使用原草稿 ID。
2. 编辑已发布文章：锁定文章后创建或复用关联草稿，线上内容不变。
3. 撤回：锁定文章和草稿；有修订草稿就保留其内容，没有则复制线上内容和标签。设置 published=false，并更新草稿版本，阻止旧窗口误保存或发布。
4. 重新发布：在事务中把草稿内容和标签应用到原文章，恢复 published=true，删除草稿。保留原 ID、创建日期和首次发布日期；旧数据缺失发布日期时补齐。
5. 删除修订草稿：原文仍已发布时仅删除草稿。
6. 删除撤回文章：不能只删草稿，需通过专用操作在同一事务中校验其仍未公开，再删除文章及级联草稿。过期列表不能误删已经重新发布的文章。

编辑页保存、草稿箱发布与删除传入 `expectedUpdatedAt`。仓储先锁文章、再锁草稿，锁后重新读取内容及标签，核对版本后写入。失败会回滚，发布后草稿再次被保存或发布会报错，不会创建空壳。AI 摘要/封面也会更新版本；编辑页仅在其他保存字段及公开状态未变化、AI 结果已经同步到界面时接受新版本。

页面操作、REST 发布/撤回/删除以及 MCP 发布/撤回统一使公开文章缓存、各语言布局、详情页、RSS 和 sitemap 失效，分类、专题和站内引用随之更新。

### 入口

- 后台已发布文章菜单、文章编辑页：「撤回为待发布」。编辑页先保存当前修改再撤回。
- 草稿箱：分别标示新文章、原文已发布的修订、已撤回待发布文章；支持重新发布。
- REST：`PATCH /api/posts/:id`，请求体 `{"action":"unpublish"}`，需要作者登录。
- 为兼容旧客户端，`PUT published:false` 仍表示保存编辑草稿，不隐式撤回；`PUT published:true` 保存并发布。
- MCP：`unpublish_post(postId, confirm:true)` 返回保留的草稿；`publish_post` 恢复原文章。旧的模糊 toggle 状态入口已移除。

## 验证

`npm test` 包含渲染与安全边界测试，以及基于项目真实迁移文件初始化的内存 PostgreSQL 集成测试。测试不读取环境文件，也不连接现有数据库，覆盖撤回与修订保留、原链接重发、作者权限、版本冲突、保存/发布和发布/撤回竞争、事务回滚、重复请求及待发布文章删除。

内存 PostgreSQL 使用单连接，覆盖事务串行结果；生产 PostgreSQL 多连接锁调度仍需部署环境集成验证。
